# EEE4015 Week 7: Security, Resilience, Communication, and Team Practice

Interactive 6.75-hour teaching presentation introducing A002 risk assessment and proportionate controls, safe-state review, communication-interface troubleshooting, maintainable software, team coordination, and individual logbook/CPD evidence.

## Run locally

```powershell
npm ci
npm run dev
```

Use the slide controls or arrow keys. Interactive controls are planning and reflection aids; they do not assess a real installation, inject a physical fault, or certify safety.

## Build

```powershell
npm run build
```

Vite writes the static presentation to `dist/`; the Pages workflow publishes it at `/EEE4015/week-07/`.

## Safety and evidence boundary

Treat the propagation cabinet as a teaching prototype, not a production or safety-certified system. Use tutor-approved extra-low-voltage setups; never switch mains-connected heaters, pumps, or fans. Fault scenarios are tabletop/simulation exercises unless the tutor separately approves a safe physical test. Keep credentials and personal data out of public repositories and screenshots. Record measured evidence separately from examples and simulations.
