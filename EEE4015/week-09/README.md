# EEE4015 Week 9: Refinement, Evaluation, and Coursework Writing

Interactive 6.75-hour A002 workshop helping students turn their own test results into an evidence-backed evaluation, prioritised recommendations, controlled refinements, regression-test records, operator guidance, and individual contribution/CPD reflection.

## Run locally

```powershell
npm ci
npm run dev
```

Use the slide controls or arrow keys. Draft fields save in this browser's local storage and can be exported as a Markdown working draft. The templates provide structure and prompts, not completed assessment answers; students must use their own project evidence and follow tutor assessment guidance.

## Build

```powershell
npm run build
```

Vite writes the static presentation to `dist/`; the Pages workflow publishes it at `/EEE4015/week-09/`.

## Evidence and safety boundary

Separate measured results, simulation, inference, and proposed future work. Preserve the original test result, record each design/code version, rerun affected and regression tests, and do not claim industrial reliability or certification from a short classroom demonstration. Follow the tutor's workshop procedures for any physical refinement or demonstration.
