# EEE4015 Week 10: Demonstration, Portfolio Review, and Continuing Development

Interactive 6.75-hour capstone for the EEE4015 module. It synthesises LO1–LO5 and A001/A002 evidence through a team demonstration run-of-show, structured individual questions, safe fallback planning, portfolio consistency review, reflection, and a measurable CPD action.

## Run locally

```powershell
npm ci
npm run dev
```

Use the slide controls or arrow keys. Reflection and final-review draft fields save locally in this browser and can be exported as a Markdown working document. The prompts support the learner's own evidence; they are not completed assessment answers.

## Build

```powershell
npm run build
```

Vite writes the static presentation to `dist/`; the Pages workflow publishes it at `/EEE4015/week-10/`.

## Demonstration and evidence boundary

State each demonstration condition, show actual behavior, explain what it proves and does not prove, and follow tutor-approved safe startup/shutdown procedures. If a live component fails, stop and use clearly labelled recorded evidence; do not bypass faults or improvise physical changes. Keep measured, simulated, and planned evidence distinct. The teaching prototype is not represented as a certified product.
